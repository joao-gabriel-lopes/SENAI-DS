Manual: Criar Projeto Expo com TypeScript e Web

1. Criar o projeto Expo com template TypeScript

Entre no diretório onde o projeto será criado, por exemplo, para criar um projeto na Área de Trabalho

cd desktop

Comando para criar um projeto chamado "nome_projeto" usando expo

npx create-expo-app nome_projeto --template blank-typescript

Contexto: Cria um projeto em branco com TypeScript pronto para usar React Native.

2. Habilitar suporte à Web

Entrar no diretório do projeto

cd nome_projeto
npx expo install react-dom react-native-web

Contexto:

  • react-dom → permite renderizar React no browser.
  • react-native-web → traduz componentes React Native para Web.
  • npx expo install → garante compatibilidade com a versão do React Native do projeto.

3. Rodar o projeto

Em seguida, inicie o Expo:

npx expo start

Isso abre o Metro Bundler, que exibe um menu interativo no terminal. Algumas opções importantes:

  • w → abre o projeto na Web (browser), usando react-native-web.
  • a → abre no Android (emulador ou dispositivo físico).
  • i → abre no iOS (emulador ou dispositivo físico).
  • q → fecha o menu do Expo.
Usando w, você pode testar seu app diretamente no browser sem precisar de emulador, útil para desenvolvimento rápido e depuração.

4. Observações importantes

  • O template blank-typescript já vem configurado para usar TypeScript, então você pode criar arquivos .tsx imediatamente.
  • O suporte à Web exige react-dom e react-native-web, que traduzem os componentes para HTML/CSS/JS.
  • O menu do Expo (Metro Bundler) permite alternar facilmente entre plataformas sem abrir IDEs complexas.
