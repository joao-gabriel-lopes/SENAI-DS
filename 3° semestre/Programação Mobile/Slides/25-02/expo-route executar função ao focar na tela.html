Exemplo Expo Router: Pesquisa + Detalhes de Alunos

1. Estrutura do projeto

app/
 ├── _layout.tsx       ← Stack global
 ├── index.tsx         ← Tela de Pesquisa de Alunos
 └── detalhes.tsx      ← Tela de Edição/Detalhes do Aluno

2. Layout global (_layout.tsx)

import { Stack } from 'expo-router';

export default function Layout() {
  return <Stack />;
}

O _layout.tsx substitui o NavigationContainer e gerencia a navegação entre telas.

3. Tela de Pesquisa de Alunos (index.tsx)

import { View, Text, Button, FlatList } from 'react-native';
import { useRouter, useFocusEffect } from 'expo-router';
import { useCallback, useState } from 'react';

export default function Pesquisa() {
  const router = useRouter();
  const [alunos, setAlunos] = useState([]);

  // Função que simula chamada à API
  async function ConsultarAlunos() {
    const dados = [
      { id: 1, nome: 'João' },
      { id: 2, nome: 'Maria' },
      { id: 3, nome: 'Pedro' }
    ];
    setAlunos(dados);
  }

  // Recarrega a lista toda vez que a tela volta ao foco
  useFocusEffect(
    useCallback(() => {
      ConsultarAlunos();
    }, [])
  );

  return (
    <View style={{ padding: 20 }}>
      <Text style={{ fontWeight: 'bold', marginBottom: 10 }}>Lista de Alunos:</Text>

      <FlatList
        data={alunos}
        keyExtractor={item => item.id.toString()}
        renderItem={({ item }) => (
          <View style={{ marginBottom: 10 }}>
            <Text>{item.nome}</Text>
            <Button
              title="Editar"
              onPress={() => router.push(`/detalhes?id=${item.id}`)}
            />
          </View>
        )}
      />
    </View>
  );
}

✅ Ao voltar da tela de detalhes, a lista é recarregada automaticamente.

4. Tela de Detalhes/Editar Aluno (detalhes.tsx)

import { View, Text, Button } from 'react-native';
import { useLocalSearchParams, useRouter } from 'expo-router';

export default function Detalhes() {
  const router = useRouter();
  const { id } = useLocalSearchParams();

  const texto = id ? `Editando aluno com ID: ${id}` : 'Novo aluno';

  return (
    <View style={{ padding: 20 }}>
      <Text style={{ marginBottom: 20 }}>{texto}</Text>

      <Button
        title="Voltar"
        onPress={() => router.back()}
      />
    </View>
  );
}

✅ A tela mostra o parâmetro opcional id e permite voltar à tela de pesquisa.

5. Observações importantes

  • O useFocusEffect + useCallback é suficiente para recarregar a lista ao voltar da tela de edição.
  • Não é necessário usar useEffect com [] porque ele só roda na montagem inicial.
  • A navegação passa parâmetros usando router.push('/detalhes?id=123') e recupera com useLocalSearchParams().
  • Essa abordagem mantém a tela de pesquisa montada em memória, preservando estados e inputs, mas permite atualizar os dados quando a tela volta a ter foco.
