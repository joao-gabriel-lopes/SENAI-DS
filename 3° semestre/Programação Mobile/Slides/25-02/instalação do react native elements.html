Manual de Instalação: React Native Elements (RNEUI) no Expo

Incluindo ajuste de dependência do react-test-renderer

1. Contextualização

Ao instalar pacotes como @rneui/themed e @rneui/base em um projeto Expo, você pode se deparar com um erro de peer dependency relacionado ao react-test-renderer. Isso acontece porque:

  • Seu projeto provavelmente usa React 19.1.0.
  • Algumas bibliotecas, como @testing-library/jest-native (dependência de @rneui/base), exigem react-test-renderer >=19.2.4 por padrão.
  • O npm tenta instalar a versão mais nova compatível (^19.2.4), mas ela não bate com o React que você está usando → conflito.

Portanto, precisamos instalar uma versão **exata do renderer** compatível com o React atual e remover o caractere ^ do package.json para fixar a versão.

2. Passo 1 — Instalar a versão correta do react-test-renderer

Execute o comando:

npm install --save react-test-renderer@19.1.0

Isso força a instalação da versão exata 19.1.0, compatível com seu React, evitando conflitos de dependência.

3. Passo 2 — Remover o ^ do package.json

No package.json, localize a linha:

"react-test-renderer": "^19.1.0"

Substitua por:

"react-test-renderer": "19.1.0"

Isso garante que o npm não tente atualizar automaticamente para versões incompatíveis no futuro.

4. Passo 3 — Instalar o React Native Elements (RNEUI)

Agora que o renderer está compatível, instale os pacotes:

npx expo install @rneui/themed @rneui/base

O expo install cuida da compatibilidade de versões com o React Native e Expo, garantindo que tudo funcione corretamente.

5. Resumo do fluxo

  1. Instalar a versão exata do react-test-renderer para coincidir com a versão do React atual.
  2. Remover o caret (^) no package.json para fixar a versão.
  3. Instalar o @rneui/themed e @rneui/base usando npx expo install para garantir compatibilidade com Expo.

6. Observações finais

  • Esse ajuste é necessário apenas se você estiver usando uma versão do React **anterior à 19.2.x**.
  • Não alterar a versão do React só para satisfazer peer dependencies evita problemas em outros pacotes ou no Expo.
  • Depois dessa sequência, você pode importar componentes do RNEUI normalmente, por exemplo:
    • import { Button } from '@rneui/themed';
