Manual: Axios com TypeScript no React Native (Expo)

1. O que é Axios?

Axios é uma biblioteca baseada em Promises utilizada para fazer requisições HTTP (GET, POST, PUT, DELETE).

Contexto: Facilita o consumo de APIs REST no React Native, oferecendo melhor organização, tratamento de erros e configuração global.

npx expo install axios

2. Axios vs Fetch

  • Axios converte JSON automaticamente.
  • Axios possui interceptadores.
  • Axios possui timeout configurável.
  • Fetch é nativo, mas exige mais configuração manual.
Axios é mais recomendado em projetos médios e grandes por facilitar manutenção e escalabilidade.

3. O que é Promise?

Promise é um objeto que representa o resultado futuro de uma operação assíncrona.

  • Pending → ainda executando
  • Fulfilled → sucesso
  • Rejected → erro
const promessa = new Promise<string>((resolve, reject) => {
  resolve("Sucesso!");
});

async function executar() {
  try {
    const resultado = await promessa;
    console.log(resultado);
  } catch (erro) {
    console.log(erro);
  }
}
O Axios funciona totalmente baseado em Promises.

4. Criando a instância do Axios

Criar um arquivo api.ts para centralizar configurações:

import axios from 'axios';

export const api = axios.create({
  baseURL: 'https://sua-api.com',
  timeout: 5000,
  headers: {
    'Content-Type': 'application/json',
  },
});

Contexto: Centralizar configurações evita repetição de código.

5. Criando o contrato (Interface)

export interface Usuario {
  id: number;
  nome: string;
  email: string;
}

Contexto: Interface define o formato dos dados recebidos da API.

6. Funções CRUD Exportáveis

Listar todos

export const listarUsuarios = async (): Promise<Usuario[]> => {
  const response = await api.get<Usuario[]>('/usuarios');
  return response.data;
};

Buscar por ID

export const buscarUsuarioPorId = async (id: number): Promise<Usuario> => {
  const response = await api.get<Usuario>(`/usuarios/${id}`);
  return response.data;
};

Criar

export const criarUsuario = async (
  usuario: Omit<Usuario, 'id'>
): Promise<Usuario> => {
  const response = await api.post<Usuario>('/usuarios', usuario);
  return response.data;
};

Atualizar

export const atualizarUsuario = async (
  id: number,
  usuario: Partial<Usuario>
): Promise<Usuario> => {
  const response = await api.put<Usuario>(`/usuarios/${id}`, usuario);
  return response.data;
};

Excluir

export const excluirUsuario = async (id: number): Promise<void> => {
  await api.delete(`/usuarios/${id}`);
};

7. Exemplo de uso no componente

import React, { useEffect, useState } from 'react';
import { View, Text } from 'react-native';
import { listarUsuarios } from '../services/usuarioService';

export default function TelaUsuarios() {
  const [usuarios, setUsuarios] = useState([]);

  useEffect(() => {
    carregarUsuarios();
  }, []);

  const carregarUsuarios = async () => {
    try {
      const dados = await listarUsuarios();
      setUsuarios(dados);
    } catch (erro) {
      console.log(erro);
    }
  };

  return (
    <View>
      {usuarios.map(usuario => (
        <Text key={usuario.id}>{usuario.nome}</Text>
      ))}
    </View>
  );
}

8. Conclusão

  • Axios utiliza Promises.
  • TypeScript garante tipagem forte.
  • Separar serviços da interface melhora organização.
  • Instância centralizada facilita manutenção.
