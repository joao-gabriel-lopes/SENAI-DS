Expo Router - Projeto Completo

Fluxo de navegação, parâmetros opcionais, botão de voltar e header customizável

1. Introdução

O Expo Router simplifica a navegação em React Native usando um modelo baseado em arquivos. Cada arquivo ou pasta dentro de app/ cria uma rota automaticamente, sem necessidade de registrar telas manualmente. O _layout.tsx funciona como wrapper global para todas as telas daquele grupo.

Ele também imita o comportamento de navegação web: você pode passar parâmetros, usar histórico (push/back/replace) e deep linking, mas ainda aproveita toda a performance do React Native.

2. Pacotes Necessários

Dentro do seu projeto Expo (blank template), instale:

npx expo install expo-router react-native-safe-area-context react-native-screens expo-constants expo-status-bar

Além disso, se não estiver instalado ainda:

npx expo install @react-navigation/native
Esses pacotes são essenciais para que o Expo Router funcione corretamente e forneça stack, parâmetros e navegação entre telas.

3. package.json

O Expo Router gerencia o ponto de entrada do app automaticamente. Para isso, você precisa que o package.json tenha o campo "main": "expo-router/entry". Isso indica ao Expo que o app deve iniciar pelo entry point do Router, não pelo padrão React Native. 

{
  "name": "meu-app",
  "version": "1.0.0",
  "main": "expo-router/entry",
  "scripts": {
    "start": "expo start",
    "android": "expo start --android",
    "ios": "expo start --ios",
    "web": "expo start --web"
  },
  "dependencies": {
    "expo": "~48.0.0",
    "expo-router": "^1.8.5",
    "react-native": "0.71.8",
    "react-native-safe-area-context": "^4.5.0"
  }
}
Sem o campo "main": "expo-router/entry", o app não reconhece o ponto de entrada do Router e você terá erro de entry file.

5. Layout (_layout.tsx) – Exemplos de Header e Título

5.0. Configuração básica (apenas Stack)

import { Stack } from 'expo-router';

export default function Layout() {
  return <Stack />;
}

✅ Header aparece por padrão, mostrando **o nome do arquivo da tela** como título.

5.1. Título único global para todas as telas

import { Stack } from 'expo-router';

export default function Layout() {
  return (
    <Stack
      screenOptions={{
        title: 'Aplicativo de Alunos', // Mesmo título em todas as telas
        headerShown: true, // Header visível
      }}
    />
  );
}

5.2. Títulos individuais por tela

import { Stack } from 'expo-router';

export default function Layout() {
  return (
    <Stack>
      <Stack.Screen
        name="index"
        options={{ title: 'Pesquisa de Alunos' }}
      />
      <Stack.Screen
        name="details"
        options={{ title: 'Detalhes do Aluno' }}
      />
    </Stack>
  );
}

5.3. Tela sem header

import { Stack } from 'expo-router';

export default function Layout() {
  return (
    <Stack>
      <Stack.Screen
        name="details"
        options={{ headerShown: false }}
      />
    </Stack>
  );
}
✅ Você pode combinar todas essas opções: título global + títulos individuais + telas sem header. ✅ A configuração básica (5.0) é útil para quem quer **usar os nomes dos arquivos como título automaticamente**.

6. Tela Home (index.tsx)

import { View, Button } from 'react-native';
import { useRouter } from 'expo-router';

export default function Home() {
  const router = useRouter();

  return (
    <View style={{ padding: 20 }}>

      {/* Com parâmetro */}
      <Button
        title="Ir para Details com id 10"
        onPress={() => router.push({ pathname: '/details', params: { id: 10 } })}
      />

      {/* Sem parâmetro */}
      <Button
        title="Ir para Details sem id"
        onPress={() => router.push('/details')}
      />

    </View>
  );
}

7. Tela Details (details.tsx)

import { View, Text, Button } from 'react-native';
import { useLocalSearchParams, useRouter } from 'expo-router';

export default function Details() {
    const router = useRouter();
    const { id } = useLocalSearchParams();

    if (id) {
        var texto = `O id é ${id}`;
    } else {
        var texto = `Nenhum id recebido`;
    }

    return (
        <View style={{ padding: 20 }}>
            <Text>{texto}</Text>

            <Button
                title="Voltar"
                onPress={() => router.back()}
            />

        </View>
    );
}
O botão "Voltar" finaliza a tela atual e retorna para a anterior, mantendo seus dados.

8. Fluxo de Teste

  1. Clique em "Ir para Details com id 10" → exibe "O id é 10".
  2. Clique em "Voltar" → retorna para Home, mantendo qualquer estado que estava lá.
  3. Clique em "Ir para Details sem id" → exibe "Nenhum id recebido".
  4. Clique em "Voltar" → retorna para Home novamente.
  5. Se houver uma tela sem header, ela aparecerá fullscreen sem barra de título.
  6. No cenário básico (5.0), cada tela mostra seu **nome de arquivo como título** automaticamente.
